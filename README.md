# Clippo

スマホのWebブラウザで使える、端末内完結型のシンプルな動画編集アプリです。

## 機能

- 動画の開始・終了位置を指定してトリミング
- 9:16 / 1:1 / 16:9 / 元サイズの切り替え
- 明るさ調整
- 音声のオン・オフ
- WebM形式で端末に保存

動画はサーバーへ送信されず、ブラウザ内で処理されます。

## ローカルで起動

静的ファイルだけで動作します。任意のローカルWebサーバーでこのディレクトリを公開してください。

```sh
npx serve .
```

## 対応ブラウザ

最新版の Chrome / Edge を推奨します。iOS Safari は `MediaRecorder` の対応状況により、書き出しが動作しない場合があります。
