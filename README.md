# Clippo Studio

「プロの編集を、もっと身近に。」スマホとパソコンのブラウザで動く無料の動画編集ワークスペース。

[公開アプリ（Vercel）](https://web-github-seven.vercel.app)

公開ベータです。[製品リリースレビュー](RELEASE_REVIEW.md)に、正式リリースを止める課題と合格条件を記載しています。

端末の自動保存は、[WebKitの保存ポリシー](https://webkit.org/blog/14403/updates-to-storage-policy/)などの容量・削除制約を受けます。永久保存やバックアップの代替は保証しません。

## 編集機能

- 複数の動画・写真を組み合わせる映像タイムライン
- トリミング、再生ヘッド位置での分割、複製、削除、並べ替え
- クリップ端のドラッグでトリミング、長押し移動、コピー＆貼り付け、分割した連続素材の再結合
- クロスディゾルブ・暗転・ホワイトフラッシュ・ワイプ（プレビューと書き出しに反映、音声もクロスフェード）
- クリップ単位の速度・音量・明るさ・画面フィット調整
- 回転・左右反転・拡大、コントラスト・彩度、色調プリセット、映像／音声フェード
- テロップの内容・表示時間・位置・文字サイズ・色・背景
- プレビュー上でのテロップ位置調整、テロップのフェード、テロップ・音楽のタイムライン移動
- BGM の配置、トリミング、音量、フェードイン・アウト
- アンドゥ・リドゥ、素材を含むプロジェクトファイルの保存と読み込み
- 16:9 / 9:16 / 1:1 / 4:5、720 / 1080 の書き出し
- ブラウザの対応状況に応じた MP4 / WebM 出力

素材はサーバーにアップロードしません。編集・書き出しは端末内で実行されます。素材合計150MBまでの最新編集1件を端末内に自動保存し、次回に復元できます。保存失敗や別タブの競合は表示します。端末保存は保証されたバックアップではありません。大切な作品は「保存」でプロジェクトファイルも手元に残してください。

## 直感的な操作

スマホはタブの切り替えなしで編集できます。素材を選ぶとタイムライン下に横スクロールの調整欄が表示され、音量（%スライダー）・速度・文字などをその場で変更できます。配置や長さの操作中も、プレビューとタイムラインを隠しません。

スマホでは「追加・おまかせ・分割・文字・音楽・削除・その他」を画面下の1段にまとめ、よく使う操作を直接開けます。「元に戻す・やり直す」は再生操作の横に配置しています。「映像をたたむ」でプレビューを折り畳み、再生操作を残したままタイムラインをさらに広げられます。

スマホはページ全体をスクロールしない編集画面です。上部のプレビューを表示したまま、下のタイムラインだけをスクロールして操作できます。ツール先頭の「＋ 追加」から、その場で動画・写真を追加します。素材を選ぶと同じ画面の調整欄から音量・速度・文字を変更でき、音楽ボタンからBGMを追加します。

タイムラインの空白をクリック／タップすると、その位置から追加できます。映像の行は素材選択、文字の行は文字追加、音楽の行は音楽棚を開きます。映像はクリック位置に近い切れ目に挿入し、目盛りは引き続き再生位置の移動に使えます。

PCではファイルを画面にドロップ、または素材棚からタイムラインへドラッグして挿入できます。挿入位置を線で示し、元のクリップを上書きしません。プレビューとタイムラインの境界をドラッグすると、高さの配分を変更できます。スマホでは素材のタップ追加、素材右側の「⠿」ハンドルを長押しして運ぶ操作、クリップの長押し移動を利用できます。

右クリック／「その他」から編集メニューを開けます。「ここから使う」「ここまで使う」は再生位置の前後を切り落とし、後ろの映像を詰める操作です。Q/W キーでも利用できます。「ぴたっと合わせる」は文字・音楽の位置をクリップの境界に合わせます。色・フェードの詳細は「もっとこだわる」にまとめています。

クリップをタップして選択し、両端のハンドルを動かすと長さを変えられます。スマホではクリップ上の短い横スワイプでタイムラインを移動し、長押ししてから左右に動かすと順番を変更できます。縦スワイプは複数段のトラックをスクロールします。目盛りをなぞって再生位置を決め、「分割」でカット。異なる素材も隙間なく並ぶため、そのまま一本の動画になります。

トリミング中は開始・終了の素材フレームをプレビューし、隣の映像やフェードに隠れず切る位置を確認できます。指を離すと通常の合成プレビューに戻ります。動画・BGMの音量は再生を止めずに調整でき、スライダーの1回の操作を1回の「元に戻す」で取り消せます。

クリップ間の「＋」から切り替え効果を選びます。重なった分だけ作品は短くなり、効果は両側の素材の半分までに制限されます。「切れ目を結合」は同じ素材から分割した、設定が同じ連続部分を元に戻す操作です。

「調整」はスマホではタイムライン下の横スクロール欄に表示します。「音量・速度・文字編集」のショートカットから目的の項目へ直接移動できます。テロップを選択して表示時間に移動すると、プレビュー上で位置を動かせます。左右の再生ボタンは 1/30 秒ずつ移動します（素材固有のフレームレートに追従するものではありません）。PC は Space で再生、S で分割、矢印で細かく移動、Ctrl/Cmd+C/V/X でコピー・貼り付け・切り取り、Ctrl/Cmd+Z で元に戻せます。

## テンプレートとBGM

- **旅のハイライト／今日のベスト／小さな日記**の3テンプレート。動画・写真を選ぶと、画面比率・カットの長さ・切り替え効果・冒頭タイトル・BGMをまとめて配置します。最大12素材の冒頭を選択順に使うルールベースの編集です。ベストシーンをAIで抽出する機能ではありません。
- テンプレートは今の編集を置き換えますが、元に戻せます。作成後も通常のタイムラインで編集できます。
- オリジナルの合成音によるお手本BGMを2種類用意。音楽ファイルの読み込み・試聴・追加も可能です。第三者の録音素材は同梱していません。
- 読み込んだ音楽と自作BGMは **IndexedDB（同じ端末・同じブラウザ・同じサイト内）** に保存します。別端末との同期はありません。ブラウザデータ削除やストレージ制限で消えることがあります。編集中のプロジェクトも素材込みで端末内に自動保存しますが、ファイルへのバックアップを併用してください。
- **BGMをつくる**では、ドラム・手拍子・ハイハット・ベースの16個のマスをオン／オフ。お手本3種類、速さ3段階、ベースの音程は自動です。4拍のパターンを8回繰り返すWAVを作り、端末の音楽棚と動画に追加します。動画が長い場合は繰り返して配置します。これは合成音の簡易ループ作成機能であり、録音・自由な作曲・AI楽曲生成ではありません。

## iPhone と形式の対応

MOV・MP4を受け付け、読み込み時に実際に再生できるか検証します。MOV はファイルの入れ物であり、映像の方式とは別です。iPhone の HEVC 動画は対応する Safari / 端末で再生できますが、全ブラウザ・全コーデックへの対応は保証しません。読み込めない場合は H.264 / AAC の MP4 に変換してください。ProRes、HDR の保持、HEIC の読み込みを保証するものではありません。

読み込みはメタデータと最初のフレームを段階的に確認します。再生時間が未確定のブラウザ録画WebMは末尾シークで回復を試みます。空ファイル・デコード失敗・タイムアウトなどは閉じるまで残るエラー欄に表示し、サムネイルだけの失敗では素材を破棄しません。iCloudなどの素材は端末にダウンロードしてから選んでください。

iPhoneの写真ライブラリを利用しやすいよう、動画・写真用の素材選択と音楽選択を分けています。選択画面のチェックマーク／追加で確定すると、自動で登録を開始し進行状況を表示します。Safari向けには画面内のミュート・インライン動画で再生準備を行います。実際のiPhone撮影HEVC素材と実機の検証は未実施です。

MP4 を出力できるかは `MediaRecorder.isTypeSupported()` で判定します。非対応の場合は WebM を利用できます。iOS では保存後の共有シートが利用可能な場合に共有ボタンを表示します。

## 現在の制限

実時間のブラウザ録画方式です。書き出しには作品と同じ程度の時間がかかり、その間は画面を表示しておく必要があります。オフラインのフレーム単位レンダリング、マルチカム、キーフレーム、色管理、プロ向け音声マスタリングなどを備えた市販の NLE と同等ではありません。長尺・多数素材・高解像度は端末メモリの影響を受けます。

Windows Chrome で自動テストを実施します。モバイル幅の表示テストは iPhone Safari 実機テストの代わりではありません。

この開発環境のChromeハードウェアH.264エンコードでは、冒頭1秒付近の短いトランジションでフレームが欠けるケースを確認しています。ピクセル単位の書き出し回帰テストはハードウェアエンコードを無効化して実施します。すべての端末で滑らかな実時間録画を保証するものではありません。公開アプリからブラウザのハードウェアエンコーダーを強制無効化することはできません。

## 開発

書き出しは30fpsを目標に合成し、自動キャプチャと手動フレーム要求の重複を避けます。スマホの初期解像度は720pです。動画のデコーダーと録画キャンバスは書き出しダイアログ内に配置します。合成が15fps未満になったり動画のフレーム更新が止まった場合は、低品質な録画を完成扱いせず中止します。ただし、この検出はすべてのエンコーダー側の不具合を検出するものではありません。

書き出し前の素材準備も進行状況に表示します。対応ブラウザでは [Screen Wake Lock](https://www.w3.org/TR/screen-wake-lock/) を要求し、書き出し中の自動スリープを抑えます。非対応・拒否時も書き出しは続行し、完了・失敗・キャンセル時にロックを解放します。画面を閉じても処理を続けられる機能ではありません。

`tests/export-smooth.test.mjs` は動く素材を書き出して完成ファイルを再生し、フレーム間隔と映像の変化をハードウェア・ソフトウェア処理の両方で確認します。意図的な低速処理で中止するテストも含みます。iPhone実機の滑らかさを保証するテストではありません。

```sh
npm install
npm run dev
# 別のターミナルで（Chrome が必要）
npm test
```

フレームワークや実行時の外部依存は不要です。`scripts/build-static.mjs` で配信対象だけを `dist` にまとめ、Vercelで静的配信します。GitHubのmainへの更新が公開版に反映されます。GitHub Pagesの既存サイトも別の保存領域として残っています。端末保存はサイト単位なので、別URLへ自動で引き継がれません。

## iPhoneの写真選択画面で確定できない場合

写真選択画面の右上の✓を押しても画面が閉じない場合、iOS側の素材準備（iCloud取得・変換など）からWebページにファイルがまだ渡されていない可能性があります。同様の症状は [WebKit bug 325067](https://bugs.webkit.org/show_bug.cgi?id=325067) に報告されています。WebページからこのOS画面を強制的に閉じることはできません。

写真アプリで動画を共有 →「ファイルに保存」→「このiPhone内」に保存し、編集画面の「ファイルから追加」から選択してください。この経路はPhotosではなく書類選択を使うための代替手段です。選択後は追加の確定操作なしでタイムラインへ登録します。MOVを受け取れても、その動画のコーデックを端末が再生できることが必要です。

ファイル受け取り・自動登録・同じファイルの再選択はChromeの自動テストで検証しています。この環境のハードウェア動画処理には不安定なケースがあるため、読み込み回帰テストでもソフトウェア処理を使用します。iPhoneのネイティブ選択画面とHEVC動画の実機検証は未実施です。
